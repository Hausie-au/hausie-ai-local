Learning methods

Thirty-one local experiments test seven different questions about your home. Only the original exact-context learner can feed suggestions; every new method is observation-only.

Scores from different tasks are not directly comparable. A matching action within 10 minutes is not proof that you wanted a suggestion. Missing labels are not counted as mistakes. Sensor and response predictions are observational, not proof of cause.

Which manual action follows a local change?

All eleven predictors see the same significant area event. Only the first user action within ten minutes labels it. Coverage and matches are separate.
